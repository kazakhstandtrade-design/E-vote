Проверка личности

Перед голосованием необходимо подтвердить личность и право участвовать в выборах. После проверки система выдаст отдельный анонимный токен для голосования.

ИИН + биометрия
Введите ИИН для проверки права голоса. После успешной проверки потребуется биометрическое подтверждение.
01
Доступ к голосованию ограничен
Для участия в голосовании необходимо достичь 18-летнего возраста.
ИИН подтверждён
ИИН прошёл проверку, возрастное требование выполнено, право голоса найдено в тестовой базе, повторное голосование не обнаружено. Для завершения проверки необходимо пройти биометрическую проверку.
ЭЦП
Подтверждение личности с использованием электронной цифровой подписи.
02
✓
Право голоса подтверждено
Система создала отдельный анонимный токен для голосования. В прототипе токен используется как идентификатор подтверждённого права голоса.
← Вернуться в личный кабинет
В текущем прототипе используется локальная тестовая база ИИНов. Проверка контрольной цифры, даты рождения и возраста выполняется на стороне браузера. Биометрическая проверка и интеграция с ЭЦП имитируются. Для реальной системы критические проверки должны выполняться на защищённом сервере с использованием официальных источников данных.
