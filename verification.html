Подтверждение права голоса

Проверка личности

Перед голосованием необходимо подтвердить личность и право участвовать в голосовании.

ИИН + биометрия
Введите ИИН. После проверки потребуется подтверждение личности с помощью биометрии.
ИИН найден
Право голоса предварительно подтверждено. Для завершения проверки необходимо пройти биометрическую проверку.
ЭЦП
Подтверждение личности с использованием электронной цифровой подписи.
Право голоса подтверждено
Система создала отдельный анонимный токен для голосования. В прототипе токен используется как идентификатор права голоса.

В текущем прототипе используется локальная тестовая база ИИНов. Биометрическая проверка и интеграция с ЭЦП имитируются на стороне браузера. Для реальной системы необходимы серверная инфраструктура, защищённое хранение данных и интеграция с государственными системами.
