Архитектура

Как работает система

Путь пользователя состоит из нескольких последовательных этапов. Каждый этап выполняет отдельную задачу.

01

Регистрация

Пользователь создаёт учётную запись и получает доступ к личному кабинету.

02

Подтверждение личности

Право голоса подтверждается с помощью ИИН и биометрической проверки или ЭЦП.

03

Анонимное голосование

После подтверждения создаётся отдельный анонимный токен, используемый для голосования.

Безопасность

Разделение личности и голоса

Архитектура прототипа предусматривает отделение идентификационных данных от самого бюллетеня.

01 / IDENTITY

Подтверждение личности

Система проверяет право пользователя участвовать в голосовании.

02 / TOKEN

Анонимный токен

Для дальнейшего голосования используется отдельный случайный идентификатор.

03 / BALLOT

Бюллетень

В полноценной системе содержимое бюллетеня не должно быть связано с личностью избирателя.
